# Source and scope

Original project inspected: https://github.com/MattStata/RNAseqWebinar

This package is a non-SLURM rewrite of the workflow as inspected on 2026-09-19. It is not a fork or byte-for-byte copy of the original repository. The scheduler/module layer and FASTQ discovery were rewritten, and the downstream Python utilities were made self-contained for this package.

See `CHANGES_FROM_ORIGINAL.md` for a file-by-file summary.
